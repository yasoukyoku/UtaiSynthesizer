# 德语滑音尺子(C + /j/ 的音节归属)

**S111 造 · S112 修过两处并搬进仓库。** 在此之前德语线没有任何仪器。

它回答的问题只有一个:**词内两个元音之间的 `C j`,那个辅音归前一个音节(coda)还是后一个(onset)?**
—— 这决定 `Schul|jahr` 与 `Mil|li|on` 谁把辅音交给滑音,而德语**没有耳裁**可用。

## 四个信号,命运不同(先读这张表)

| | 信号 | 判据 | 资历 |
|---|---|---|---|
| **S1** | de.wikt 的**重音相邻** | ˈ/ˌ 紧挨 /j/ ⇒ coda;紧挨 C ⇒ onset | ✅ **双向可用**,预注册对照组 **17 一致 : 0 相反** |
| **S2** | 滑音写法 **⟨i̯⟩ vs ⟨j⟩** | 写成 ⟨i̯⟩ ⇒ onset | ✅ **单向**;12 条 CODA 对照上全部沉默(单向信号该过的那一关)|
| **S3** | en.wikt 的**显式音节点** | 点落在 C 与 j 之间 ⇒ coda | ⚠⚠ **对照组上从没定过案**(0 / 0 / 24);换个更松的口径它开口两次、**两次都错**(`Linie` `Spanien` 的次要变体)⇒ **不许单独当判决** |
| **S4** | de.wikt 的 **Worttrennung** | 正字法断词 | ⚠ 当**音节数**尺子**已证伪**(`Mil·li·on` 3 节 vs IPA 2 节);当**语素边界**旁证好用。**结构上只会支持 CODA**,不是双向信号 |

⚠ **两个源不独立**(维基之间互抄)⇒「两源一致」只能读成「至少没互相矛盾」。
⚠ **覆盖率 44–66%**,而「沉默 ≠ 支持」。

## 文件

- `wikt.py` / `enwikt.py` —— 两个维基的 MediaWiki API 批量抓取器(尊重 `Retry-After`,
  **「查过但没有」也缓存**,所以覆盖率是可复算的)
- `wikt_cache.json` / `enwikt_cache.json` —— ★**最贵的资产**:2000+ 标题的 wikitext 原文,
  限速抓下来的。**动它之前先快照。**
- `ruler.py` —— 四个信号 + **预注册对照组**(28 条,每条带「凭什么不容争辩」)
- `c24_lib.py` —— 共享底座:**解析**生产常量(零手抄)+ `WordDict::from_tsv`/`syllabify`/
  `compound_seams` 的逐行等价物。`C24_G2P_REV` 在这里实现
- `s111_lib.py` —— 位点级枚举 + de.tsv 键 ↔ 维基标题的桥
- `measure.py` / `run.py` / `targets.py` / `proposal.py` —— 三个人群的测量驱动
- `blast_c24b.py` —— 累计血径的独立复算(**被 g2p.rs 的闸点名**)
- `open_costs_manifest.py` —— 未决键清单的生成器
- `mutate_harness.py` —— 变异探针的公共件(sha / 编译失败判据 / panic 正文抽取)

## ⛔ 它已经栽过的地方(别再走一遍)

1. **选点规则含被测变量** —— 按「与 de.tsv 的音素对得上」挑位点,而假设正是「那个音素的清浊
   决定答案」⇒ 反面证据变沉默,输出 `0 refuted`。**已修成清浊中立**(`ruler.DEVOICE`)。
2. **过滤器无条件生效** —— 单位点转写也被过滤掉。**已改成只在多位点时才挑**。
   (①②**两个旋钮合起来**才是 S111 那张被污染的表的成因,单独关掉任一个都不够。)
3. **合议规则求并集**(`merge()`)—— 次要变体会顶掉主读音。**已判负,函数留着只为那条负结果的正文。**
4. **汇报层吞掉「变体离散」** —— 一个由两条互相矛盾的转写、靠列表次序定案的判决,
   印出来会像一个干净的判决。**已补一列。**
5. **工装手抄生产常量** / **两臂都指向工作树** —— 见上面的 `C24_G2P_REV`。
